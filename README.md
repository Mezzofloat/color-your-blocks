This is meant to be an extension to the Colour Your World resource packs seen [here](https://www.youtube.com/watch?v=1hVX08jWaHE).
I also used Gneiss Name's Mean Shift Resource Pack seen in [this video](https://www.youtube.com/watch?v=HuW9qJbL0xM)

# Why I Did This
One thing in Colour Your World that I don't like is how every block is assigned a singular color that defines it. In trying to fix this, I will add each texture to multiple colors, and a python script to merge them together. (If you want to, you can create a mod to make this work from entirely within Minecraft. However, that's outside my realm of expertise!)
